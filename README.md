A classic Wordle-like game built with React. This project was created as a hands-on exercise to learn and practice core concepts of the React framework.

## 📖 About The Project

This is a simple clone of the popular word-guessing game, Wordle. The goal was to build a complete, interactive web application from scratch using React, focusing on state management, component-based architecture, and handling user input.

## 🎯 Learning Goals
- Component-Based Architecture: Structuring the UI into reusable components (e.g., Grid, Row, Tile, Keyboard).
- State Management: Using React hooks (useState, useEffect) to manage game state, such as the current guess, guess history, and game status (win/loss).
- User Input: Handling both virtual keyboard clicks and physical keyboard presses.
- Conditional Rendering: Displaying different UI elements based on the game's state.
- Styling in React: Applying styles to components to create a clean user interface.

## 🎮 How to Play
1. You have 6 attempts to guess a secret 5-letter word.
2. Type your guess and press Enter.
3. After each guess, the color of the tiles will change to show how close your guess was to the word.
  - 🟩 Green: The letter is in the word and in the correct spot.
  - 🟨 Yellow: The letter is in the word but in the wrong spot.
  - ⬜ Gray: The letter is not in the word in any spot.
4. Use the feedback to narrow down your next guess. Good luck!

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You'll need to have Node.js and npm (or yarn) installed on your machine.

### Installation

Install NPM packages:

```
npm install
```
Run the application:

```
npm run dev
```

This will run the app in development mode. Open http://localhost:3000 to view it in your browser.
